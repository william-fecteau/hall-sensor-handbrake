Connect the handbrake

Plug it in, click Connect and pick the CircuitPython serial port. Only one program can use the port, so close any serial monitor first (Mu, Thonny, test.bash…).

No status from the board

The port is open but the handbrake code is not reporting. It may have stopped (error or Ctrl+C). Restart it, or check the board messages below.

Not calibrated yet

Leave the handbrake fully released, then click Calibrate. You'll then have 30 seconds to pull it slowly all the way a few times. The calibration is saved on the handbrake: you only do this once.
